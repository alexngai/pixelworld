# @pixelworlds/city-sf

## 0.1.0

### Minor Changes

- d019be2: The first npm release of San Francisco's city pack: `cityPlugin` (its worker module beside it, `dist/worker.js`, self-contained and found through `new URL("./worker.js", import.meta.url)`), `register()` and the generators, with types. `pixelworld` is a peer dependency.
- 3dcd417: `lanterns` takes `lines: 1`: its wire is drawn as a one-pixel line sagging smoothly, the lanterns hung round it (needs the `pixelworld` that draws models' lines). Off by default.

### Patch Changes

- 30d36fd: `decoTower` takes a `spire` parameter: the finial's height over the tower's (default 0.05, as before), for a needle like the one on New York's generic steel-crowned tower.
