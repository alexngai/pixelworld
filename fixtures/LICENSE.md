# World packages: ODbL 1.0

The world packages in this directory are databases derived from
OpenStreetMap and Overture Maps data, which are licensed under the Open
Data Commons Open Database License (ODbL) 1.0. The packages are therefore
made available under the ODbL 1.0 as well:
https://opendatacommons.org/licenses/odbl/1-0/

Other inputs are public domain or under licences compatible with this
(USGS 3DEP: public domain; ESA WorldCover and the WRI/Meta canopy height
maps: CC BY 4.0; DataSF: ODC PDDL 1.0). Each package lists every source and
its licence in its manifest's `attribution` field, which the viewer shows
(press I). Images rendered from these packages are Produced Works under the
ODbL and must credit those sources.

See docs/data-sources.md §6 for the rules we follow.

The code that builds and draws these packages is licensed separately (MIT OR
Apache-2.0, see the repository root).
