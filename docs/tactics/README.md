# Hold the Block: tactics docs

Hold the Block is a turn-based tactics game on pixelworld's real cities
(`apps/tactics`, rules and solver in `packages/tactics`). Its decisions are
logged with the rest in [../decisions.md](../decisions.md) (D-149 onward).

| Document | What it covers |
|---|---|
| [map-survey.md](map-survey.md) | Finding good boards across a city: the scores (interactables, readability, character), character zones, election, rooftop maps and chasms, simulation, validation |
